# yen-forecast

Research project on USD/JPY. Target 0: forecast and study the yen, with every forecast evaluated against a random-walk benchmark. Target 1 (current): how USD/JPY's daily sensitivity to the Japanese 2-year yield changed from yield curve control (2016) through its dismantling (2022-24) to after the exit (2024-26), and whether the post-2025 decoupling from the 10-year differential also shows at 2 years. Work in progress.
